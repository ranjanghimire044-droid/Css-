Short Explanation

CSS Selectors: Selectors identify HTML elements that need to be styled.

CSS Units: Units such as px, %, em, rem, vw and vh control dimensions and text sizes.

CSS Colors: CSS supports different color formats including names, HEX, RGB, RGBA, HSL and HSLA.

Typography: Typography properties control the appearance and style of text.

Text Properties: Text properties control alignment, spacing, decoration, transformation and readability.

Image Properties: Image properties control image size, shape, transparency, fitting and position.

Profile Card: The profile card combines selectors, units, colors, typography, text and image properties into one practical design.
